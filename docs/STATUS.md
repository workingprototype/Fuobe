**Legend**

| | meaning |
|---|---|
| ✅ | **Verified**: run end to end here (unit tests, a live ComfyUI, the browser) |
| 🟢 | **Built**: implemented against verified API schemas or validated workflows, and the UI flow checked in demo mode, but not yet run with real paid keys or real GPU weights |
| 🟡 | **Partial**: works, but approximates Higgsfield or misses part of the feature |
| ⬜ | **Not started** |

**What "verified" can't cover on this machine:** there are no paid API keys and no GPU here. Every cloud model call and every open-source model output is therefore 🟢 at best: request shapes come from the providers' own schemas, and every ComfyUI graph is accepted by a real ComfyUI. The real outputs come from the tools that need no model weights, which ran on a CPU ComfyUI here: joining clips (also the packet-copy join), palette match, trim, cutting a segment, adding a soundtrack (one track, or a voice over a background bed), caption burn-in, the dub voice timeline, joins that keep a clip's sound, extract frame, VHS meta-batch passes, Ken Burns moves, music loops and audio joins with crossfades, VTracer vectorizing, SDR to HDR (HDR10 and EXR frames), pro export (ProRes, H.265 10-bit, FFV1, EXR), and the window, sound and work-size parts of the object-removal graphs. Three model steps also ran on CPU: MoGe 2's 3D scene with its real weights, and FPS Boost (RIFE) and Real-ESRGAN in passes with random-weight stand-ins, so their output quality wasn't judged. App features that need no model (the library, live updates, notifications, sign-in, the Layers editor, browser color grading, the ⌘K palette) are verified in the browser.

## 3. Known issues and caveats

Most important first.

**Not run for real (no keys, no GPU)**
- **Paid providers are untested with real keys.** That includes round 3's response shapes (Seedream layer boxes, Recraft's returned `style_id`, transcript cues, 3D files, Demucs stems, the fal FFmpeg tools) and round 4's routes: Topaz Video by size, Starlight, ByteDance and FLUX.3 Upscale, Topaz FPS Boost and SDR to HDR, LTX 2.3 HDR's EXR zip, the Bria erasers, VOID, LTX clean plate, SAM 3.1 masks, hosted VACE, P-Video Replace, Genjutsu and Genjutsu Lite, FLUX 3 Max keyframes, Marigold V2, fal's Ken Burns and merge-audios, and the cloud dub's split, loudnorm and mix. Prices are list prices; ByteDance's 6K and 8K prices are extrapolated from 4K, and Genjutsu's 50% promotion is mentioned, not subtracted. Assumptions from the docs: fal compose cuts an audio keyframe at its `duration` and renders an audio-only timeline over a still; cloud `join-clips` keeps each clip's audio.
- **Open-source quality is unverified.** Round 3 added about 165 GB of model files (plus about 9 GB that nodes download on first use) that have never run here. Round 4's heavy open workflows were only accepted by ComfyUI, not run: Wan 2.1 VACE (remove, swap, insert), VOID, Wan Animate 2, SeedVR2 in passes, Frames films, the Qwen-Image-Edit 2511 + Multiple-Angles re-render and a full open Faceless render. Whole open chains (a UGC presenter film, a Faceless episode, a dub with lip re-sync, a Shorts restyle) ran only on the demo provider.
- **Assist hasn't talked to a live model.** The streamed Claude call is tested against an SSE fake and Ollama against a fake server. Skills, projects and memory work end to end with the offline planner only. Small local models follow tool instructions less reliably.

**Gaps that change what a user gets**
- **Home's Start spends money.** Start (or Enter) on Home now runs the job; with a saved key for the default model that is a paid run (for example a Seedance 2.5 clip). The line under the box, which says what will run and what it costs, is the only warning. A link from elsewhere can't start a run.
- **Remove object:** seams between pieces (cloud) and windows (open) are untested, and open typed windows are joined with hard cuts. Click it and Paint it need the browser to decode the first frame (not ProRes, for example), and there is no server-side fallback. Click it is cloud only. On the open engine SAM 3.1 tracks at most 4 objects. Erasers that work in 4- or 8-frame steps (VACE, VOID, LTX) leave out up to 7 frames at the end (the estimate says so). Try again uses the form as it is now, not the run's own request.
- **Genjutsu:** with only a Higgsfield key, only a whole clip ≤15 s (≤30 s on High) can run; there is no Higgsfield-side cut or join. The references panel counts to 10, though no model uses more than 8, and open swap and insert use only the first. Clips over 30 fps aren't resampled for the hosted VACE. Higgsfield's batch, community presets and Recreate aren't built, and Katana still uses the full Genjutsu Motion Transfer, not Lite. Assist and MCP can't run Genjutsu or Remove object yet.
- **The Higgsfield provider is still in use.** The Originals research records a decision to drop the Higgsfield API; `main` doesn't act on it yet: Genjutsu still defaults to Higgsfield when a key is set, and Soul, Cinema Studio 4.0 and the other Higgsfield models still call Higgsfield's API (§4, O7).
- **FPS Boost, SDR to HDR and Export on the open engine:** FPS Boost, SDR to HDR and EXR still load the whole clip; Generate is greyed when a clip needs more than half of ComfyUI's RAM (5 s of 1080p at 24 → 60 fps is refused on a 32 GB ComfyUI). HDR is H.264 High 10 (core ComfyUI has no H.265 encoder; H.265 HDR10 is cloud only). "ProRes 422 HQ" carries 4:4:4 samples. SeedVR2 restores each 33-frame pass on its own, so seams are possible (not measured). A cancelled or failed pass leaves an idle ffmpeg and a partial .mov in ComfyUI's output folder.
- **Frames:** in an open film each still is on screen for two video frames (about 1/8 s). Ten stills mean nine or ten 20-step Wan clips on your GPU: free, but slow. On Lightning the stretch after the last frame is a 4-step clip next to 20-step pairs. Reuse on an open Frames film brings back the join step, not the frames.
- **3D scenes:** the open MoGe mesh drops sky and far-away areas, leaving empty space for the re-render to fill. Every cloud scene depends on Marigold returning the Spectral colour map of fal's example output, the only thing the decoder was checked against. The open re-render is told the LoRA's reference pose with the capture as image 1; that is untested on a GPU.
- **Some models are in the catalog but no studio page offers them.** Gemma 4 speech translate and the cloud Overlay image, Extract frames and Images to video are hidden (API only; no chain uses the last three on `main` yet). SAM 3D Objects, Meshy 7.1 Multi-view, Tripo H3.1 Text to 3D, TripoSplat, Florence-2 OCR, Bria Expand and Image to SVG (VTracer, hosted) run from a Canvas model node or the API; Meshy Rigging only through the API. In the ⌘K palette, 33 models, those of Remove object, Genjutsu, FPS Boost / SDR to HDR / Export and the 3D scene among them, open the filtered Models page instead of their own studio.
- **Mixed Media on the cloud is a video-to-video restyle**, not Higgsfield's per-frame pipeline (the per-frame route is on an unmerged branch, §4).
- **Open-engine limits.** ACE-Step makes up to 240 s of music; Faceless loops it with crossfades up to 600 s, and loops (Faceless and Audio → Loop) stop at 600 s on both engines. The joins that keep a clip's sound hold every frame in RAM at 25 fps (about 1 GB per 8 s at 480x848). InfiniteTalk lip re-sync is capped at 40 s per job (for dubs, the whole source length). Whisper captions refuse clips that need more than half the server's RAM (the estimate isn't measured).
- **Qwen-Image-Edit keeps the first image's shape** on the open engine. Photodump, Fashion Factory and Character Sheet turn the aspect picker off and say so; the open Character Sheet asks for a landscape photo first.
- **Layers:** text detection is cloud only on `main` (no open OCR model; on the open engine you type the lines to change). A decomposition that finishes while the editor is closed is laid out only when the project is opened (the server can't decode PNG alpha). Upscale doesn't resize the document; downloads use the layers' detail instead.
- **Cinema Studio:** Cinema Studio 4.0 runs at up to 720p through the public API. Open routes take no reference clips. Collaboration and community publishing are out of scope. Spend uses the estimate stored at creation for takes deleted for good, so it can be slightly over-counted.
- **Shorts Studio:** the 9:16 crop is a plain centre crop (no subject tracking). Kling O3 4K's 720 px minimum input isn't checked. The one-submit-per-click guard (`requestId`) is in memory, so a restart forgets it.
- **Marketing:** Click to Ad videos have no logo end card on `main` (the logo is used by the Ads Studio compositor and the brand line in prompts). Brand kits are matched by host and port, so one site on two ports gets two kits. An Ad Multiplier reference whose header Fuobe can't read gets a picture-only join.
- **Faceless / Explainer:** one narration take per episode, re-timed to the scenes; stage two waits for it, so a first render takes a few seconds longer and a narration change takes two passes. Every new channel draws an avatar (about $0.15 on the cloud). Scripts over 64 KB are flushed without keepalive, so the last edit may not survive closing the tab. The first change, retime or Retry of an older Frame by frame episode re-makes all its clips as Ken Burns moves. The cloud Ken Burns zooms only (no pan; it always starts or ends on the whole picture). A plain open ACE-Step bed (no loop) is still cut off when the film gets shorter. Upscale to 1080p is still offered on an episode that is already 1080p (it stops with "already 1080p").
- **Audio Loop and Join on the cloud:** whole plays (a loop can come out longer than asked; the result says its real length) and hard cuts only.
- **Clips whose header neither reader knows** (MP4 / MOV and WebM / Matroska are read) fall back to coarse defaults: caption windows to the millisecond, InfiniteTalk at 16:9 and its frame cap, a mux bed as long as the longest known track.

**Library, data and security**
- "Move to" and "new folder" in the Library's selection bar still act on the whole selection, including results hidden by a search or filter; the count and the other actions follow the shown results.
- Without Web Locks (plain `http://` on a LAN IP) each visible tab reads its own live stream; six or more visible windows on one host could hit the browser's connection limit.
- **Sign-in is off by default.** Without a password Fuobe answers only on local addresses and names in `FUOBE_ALLOWED_ORIGINS`, but anyone who can reach it can use it (and your keys). With a password, a page that rebinds DNS can still post password guesses; the throttle caps that at roughly 15–20 a minute. Without `FUOBE_TRUST_PROXY=1` behind a reverse proxy, all visitors share one throttle (slowed, never locked out). `comfyLorasDir` and `aiToolkitDatasetDir` make the server write files where you point them. Save & test lets a signed-in caller make the server fetch a ComfyUI or Ollama address without saving it (saving it already allowed the same).
- `MAX_INLINE_TEXT` caps a result's inline text at 64,000 characters; `meta.cues` of a very long transcript stays inline.
- The first routing check after the Ollama or ComfyUI URL changes can hold a request for up to 1.5 s when the host doesn't answer.

**UI leftovers (small)**
- Canvas: keystroke → paint is 19 ms at 60 nodes and 29 ms at 120 (target 16 ms).
- Layout shift: in a browser that never opened Home, on an install that is already connected, the Get started card shows briefly once (about 0.16 desktop / 0.38 phone). Home's demo-mode line still shifts the page by about 0.03 for returning users, and a brand-new browser on an install with results shifts about 0.033 on desktop when Recent arrives.
- At a 4× CPU slowdown, the first visit to Marketing after a hover takes 760–923 ms against 493–649 ms before (pages now prefetch on hover instead of at load).
- Settings' Engine mode section still sits above the providers. Layers, Captions, Trim and Translate open from the palette without preselecting the picked model.
- When Assist asks which still to animate, a length given earlier ("for 5 seconds") isn't carried over to the bare-number reply.
- In Frames mode, reference images left in the draft still count in the folded "N attached" chip but aren't sent.
- The Faceless wizard can show several `<main>` elements after a client-side navigation, and its phone footer price line wraps between the two buttons.
- `shell.mjs`'s last step ("Show more focuses the first new card") is timing-sensitive on a cold dev server.
- The files route logged "ReadableStream is already closed" once when a crashed test browser dropped its connections; not reproduced.

**Environment and licences**
- **Licences:** FLUX.1 / FLUX.2 [dev], inswapper (ReActor), MMAudio weights, USO's FLUX.1 base, ComfyUI-Whisper (opt-in with `NC_PACKS=1`) and TRIBE v2 are non-commercial. VOID's weights are Apache-2.0, but its CogVideoX-5B base is under the CogVideoX licence: commercial use only after registering, and at most 1 million service visits a month without a further licence. HunyuanVideo-Foley and Hunyuan3D 2.1 exclude the EU, UK and South Korea. Stable Audio 3 uses the Stability Community licence (free under US$1M revenue); Krea 2 has its own community licence. Settings → About & licences lists each open model's licence (a guide, not legal advice). See `research/comfyui-oss.md`, `-2.md`, `-3.md` and `-4.md`.
- **GPU sizes** (from the manifest, not measured): Remove object and Genjutsu swap / insert on Wan 2.1 VACE 14B need 24 GB (a 34.68 GB fp16 file); VOID 24–40 GB; SeedVR2 in passes 16 GB.
- **Node packs:** open video upscaling and FPS Boost now need ComfyUI-VideoHelperSuite (core ComfyUI was enough before), and open Vectorize needs ComfyUI-ToSVG. `scripts/comfy/install-comfyui.sh` installs both; on ComfyUI set up another way (for example ComfyUI Desktop), install them yourself. LatentSync 1.6 and ThinkSound run only on the isolated worker (Settings → Isolated worker URL, or `COMFYUI_ISOLATED_URL`); without it those jobs fail with a message naming the setting.
- **Wan 2.1 LoRAs on Wan 2.2:** most viral-effect LoRAs were trained for Wan 2.1 I2V; some may need a lower strength or only the low-noise expert.
- **Sunsets:** Sora 2's API was retired (2026-09-24), so it isn't offered; Veo 3.1 on fal ends 2026-11-17 (the Replicate route stays). Kling 4.0's fal routes are playground-only, so it isn't offered.
- **Headless Chromium has no H.264**, so video checks here used WebM and demo MP4 thumbnails look blank in screenshots; for the same reason Remove object and Genjutsu showed their first-frame fallbacks in the browser checks. MP4 playback is unaffected in normal browsers.
- **Dev server:** after adding routes, or after an edit to `globals.css`, Turbopack's cache can get stuck or serve stale styles. `pnpm dev:clean` clears `.next` and restarts. Without `.next`, `pnpm typecheck` fails on the route type globals until `pnpm exec next typegen` (or a dev or build run) has made them.

## 5. How to reproduce the checks

```bash
pnpm install
pnpm typecheck && pnpm lint && pnpm test && pnpm build   # in a checkout without .next, run `pnpm exec next typegen` (or a dev or build run) before typecheck
```

Browser checks need the app running (`pnpm dev`, or `pnpm build && pnpm start`); demo mode with no keys is fine. They use Playwright: the repo's `playwright` / `playwright-core` if it resolves, else a global install, and `$CHROMIUM_PATH` or the newest `/opt/pw-browsers/chromium-*`.
