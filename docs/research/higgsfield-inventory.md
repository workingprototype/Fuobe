# Higgsfield AI — Product Inventory for Fuobe (1:1 replica research)

**As of:** 2026-10-16 · **Target:** higgsfield.ai (Higgsfield, Inc., San Francisco) · **Companion data:** `higgsfield-inventory.json` (same folder)

> **Method.** Higgsfield's web app is a TanStack Start SPA with server-rendered marketing/preset pages. Research combined: (1) all 8 public sub-sitemaps (marketing, apps, 229 `/motion/<uuid>` preset pages, mixed-media presets, blog, creator-hub, originals, projects); (2) SSR HTML of ~150 pages incl. every `/apps/<slug>` page (titles, upload slots, **credit cost shown on the Generate button**); (3) the site's **i18n route catalogs** (`/_i18n/routes/en/*.json`, ~20k UI strings: labels, validation errors, limits) which expose the logged-in UI copy of the Image, Video, Cinema Studio, Pricing, Popcorn, Lipsync, Supercomputer screens; (4) the production JS bundles (job-type enum, model-id maps, preset families); (5) the Help Center (84 articles) and the full **Changelog** (Jun–Oct 2026); (6) the public **API docs** (docs.higgsfield.ai, 84 model endpoints with JSON schemas) and API price list; (7) Higgsfield blog posts plus third-party reviews. Logged-in screens were **not** directly observed — layout statements derived from UI strings/help articles are flagged *(inferred)*. Confidence levels are repeated in the JSON.

**Big-picture changes vs. 2025 (memory-based expectations):** Higgsfield is no longer "Higgsfield DoP + a few apps". In Oct 2026 it is an "AI-native creative suite" with: 30+ third-party models + own models (Soul 2.0, Soul Cinema 1.5, DoP, Popcorn, Genjutsu, Speak 2.0); **Cinema Studio 4.0** (on Seedance 2.5); **Supercomputer** (agent that replaced "Higgsfield Assist"); **Genjutsu**, **Katana**, **Ads Studio**, **Marketing Studio**, **AI Influencer Studio**, **Canvas**, **Layers**, **Audio**, **Faceless Studio**, plugins, MCP/CLI, a public **pay-per-use API** (launched 2026-09-16), Community "Open Projects", Academy, contests, Originals. **Sora 2 was removed** after OpenAI retired the API on 2026-09-24 (drafts auto-move to Seedance 2.5).

## 8. UX details that make it feel good (to replicate)
1. **Cost transparency:** credit cost always on the Generate button, recomputed live; upsell copy when insufficient ("Not enough credits", "{needed} credits needed", "Top up").
2. **Smart validation & auto-correction:** per-model limits enforced client-side with precise messages (file ≤20 MB, min 300×300, AR 0.4–2.5, max refs, total video+audio ≤15/30 s, prompt length 2,000–20,000 chars); auto-adjusts incompatible settings with a toast; "Change to 720p 8s for unlimited" quick-fix chips; video **trimmer** for over-long uploads ("Select a 15-second segment").
3. **Progress UX:** optimistic card insertion into the feed ("withFeedOptimistic"); states *Queued / In queue / In progress / Generating / Almost there, hang tight… / Taking longer than expected – try refreshing*; time left "{m}m {s}s left", elapsed/total; high-demand banners ("Kling 3.0 is experiencing high demand"; "Your wait time > 30 min" with upsell for priority); Cancel with confirmation; failures show reason and **"Credits refunded"**; browser notifications ("Your task is ready").
4. **Feed/history:** per-section feed + global Assets; filters (All/Images/Videos/Liked, by model/type/date), masonry/grid, fit/fill previews, split by date, infinite "Load more"; failed/hidden filters; folders & projects with drag-and-drop.
5. **Reuse loops:** *Recreate* (restores model + settings + prompt), *Reuse prompt / Copy prompt*, *Rerun*, *Use in image / Use in video / Turn to video / Animate* (image→video handoff), *As Start Frame / As End Frame / As Reference*, *Extract Start/End Frame* from video, *Save as Element*, *Send to Canvas*, *Open in Cinema Studio*, *Upscale*, *Edit*, *Extend*, *Lipsync*, *Recreate with Soul 2.0 / Soul Cinema*, community *Recreate this example*.
6. **Asset actions:** Download (single/"Download All", EXR per-file, "Just your generated video" vs with reference), Copy link / image URL, Share to X/LinkedIn/Pinterest/WhatsApp, Like/heart → Favorites, Add to folder / Move to / Copy to workspace, Publish/Unpublish to profile, Comment (time-coded, free-draw annotations, emoji reactions, resolve), Delete → Trash (30 days; uploads deleted permanently), Compare before/after slider, Split view.
7. **Bulk selection:** multi-select with bottom action bar (Download, Publish all, Add to folder, Like, Delete), "Unselect All (Esc)".
8. **Prompt ergonomics:** `@` mentions for Elements/uploads (auto-hyperlinked tokens, renumbered on removal), `#` camera-move tags in Cinema Studio, "Image 1 / Video 1 / Audio 1" referencing, Enhance prompt toggle with "Enhanced prompt copied", prompt guides/presets, "Put on prompt".
9. **Keyboard:** Ctrl/⌘+Enter to submit (shown as "Ctrl ↵" in Supercomputer), Esc to clear selection, paste images from clipboard; Cinema Studio next/previous era/genre/tempo controls.
10. **Upload trust & safety:** async IP/face eligibility checks with states ("Checking content…", "This image contains faces or IP and cannot be used", "Confirm rights"), NSFW masking, consent checkboxes for biometric data.
11. **Monetization nudges:** Unlimited toggles, countdown personal discounts, "You've spent 25/50/80% of your credits", free-gen campaigns, rewards tasks in notification bell — (optional for an open-source clone).
12. **Collaboration:** shared projects/folders, roles, request-access, real-time presence ("Online now", "Creators generating now"), shared Elements.
