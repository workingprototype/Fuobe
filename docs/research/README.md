To refresh: re-run the research, then `pnpm gen:catalog` (cloud models, Higgsfield models and presets, LoRA map) and `pnpm test` (catalog integrity tests catch broken references). Workflow changes go through `scripts/comfy` (`npm run build -- <ids>` and `node validate-workflows.mjs <ids>` against a live ComfyUI).
